
# Ordinary Least Squares (OLS)

Ordinary Least Squares (OLS) is the mathematical method used to find the best-fitting line in Linear Regression.

It finds the line that minimizes the sum of squared errors (residuals) between the actual values and the predicted values.

OLS is the foundation of Linear Regression.


# What Problem Does OLS Solve?

Suppose we want to predict house prices.
    
    House Size (sq ft)	    Price ($)
    1000	                  200000
    1500	                  300000
    2000	                  400000
    2500	                  500000

There are many possible lines that could fit these points.

OLS finds the best one.

# Linear Regression Equation

The model is

y=mx+c

or in machine learning notation

y=β0+β1x

Where:

* x = Input feature
* y = Target
* β₀ = Intercept
* β₁ = Slope (coefficient)

OLS calculates the values of β₀ and β₁.

# What is a Residual?

Suppose

Actual house price

    $400,000

Predicted

    $380,000

Residual

    400000 − 380000 = 20000

Residual = Actual − Predicted


# Why "Least Squares"?

Suppose we have four residuals.

    10
    
    -5
    
    20
    
    -25

If we simply add them:

    10 -5 +20 -25  =  0

The errors cancel each other.

That is not useful.

Instead we square them.

    10² =100
    
    (-5)²=25
    
    20²=400
    
    (-25)²=625

Now,

    100+25+400+625
    
    =1150

All errors become positive.

# Step-by-Step Example

Suppose
    
    X	        Actual Y
    1	            3
    2	            5
    3	            7

Suppose the model predicts
    
    X	        Predicted Y
    1	            2.8
    2	            5.1
    3	            6.9

Residuals
    
    Actual	        Predicted	        Residual
    3	                2.8	                0.2
    5	                5.1	               -0.1
    7	                6.9	                0.1
    
## Squares

    0.2² = 0.04
    
    0.1² = 0.01
    
    0.1² = 0.01

## SSE

    0.04+0.01+0.01=0.06

OLS tries to make this value as small as possible.

# How OLS Finds the Best Line

Imagine many possible lines.

    Line A
    
    \
     \
      \

    Line B
    
     -----

    Line C
    
        /
       /

OLS calculates the SSE for every possible line and chooses the one with the minimum SSE.

# Why Square the Errors?

Three reasons:

## 1. Positive Values

Negative errors do not cancel positive ones.

## 2. Larger Errors Get More Penalty

Example

    Error = 2
    
    Square =4

    Error =10
    
    Square =100

A large error is penalized much more.

## 3. Easy Mathematics

Squaring produces a smooth, differentiable function that has a unique minimum (under standard assumptions), making it possible to solve analytically or optimize efficiently.

# OLS Assumptions

OLS works best when these assumptions are approximately true:

1. Linear relationship between features and target.
2. Independent observations.
3. Constant variance of errors (Homoscedasticity).
4. Residuals are approximately normally distributed (important for statistical inference).
5. No severe multicollinearity among predictors (for multiple linear regression).

Advantages
Simple and easy to understand
Fast for small datasets
Produces interpretable coefficients
Closed-form mathematical solution
Strong statistical foundation
Disadvantages
Sensitive to outliers
Assumes a linear relationship
Can struggle with multicollinearity
Matrix inversion becomes expensive with many features
Can overfit if there are many irrelevant features
