
# Ordinary Least Squares (OLS)

Ordinary Least Squares (OLS) is the mathematical method used to find the best-fitting line in Linear Regression.

It finds the line that minimizes the sum of squared errors (residuals) between the actual values and the predicted values.

OLS is the foundation of Linear Regression.


# What Problem Does OLS Solve?

Suppose we want to predict house prices.
    
    House Size (sq ft)	    Price ($)
    1000	                  200000
    1500	                  300000
    2000	                  400000
    2500	                  500000

There are many possible lines that could fit these points.

OLS finds the best one.

# Linear Regression Equation

The model is

y=mx+c

or in machine learning notation

y=β0+β1x

Where:

* x = Input feature
* y = Target
* β₀ = Intercept
* β₁ = Slope (coefficient)

OLS calculates the values of β₀ and β₁.

# What is a Residual?

Suppose

Actual house price

    $400,000

Predicted

    $380,000

Residual

    400000 − 380000 = 20000

Residual = Actual − Predicted


# Why "Least Squares"?

Suppose we have four residuals.

    10
    
    -5
    
    20
    
    -25

If we simply add them:

    10 -5 +20 -25  =  0

The errors cancel each other.

That is not useful.

Instead we square them.

    10² =100
    
    (-5)²=25
    
    20²=400
    
    (-25)²=625

Now,

    100+25+400+625
    
    =1150

All errors become positive.
