 
# Introduction
 
Time series modeling is a set of tools and techniques that model temporal or time series data and aim to predict or forecast future behavior of the data. 
It has applications in various fields such as finance, economics, weather forecasting, and more.


By analyzing historical data, we can identify different components in time series data such as trends, seasonality, and so on, and 
use these insights to make more informed business decisions.


There are few different techniques for time series modeling. As we construct and evaluate our models, we'll gain insight into how 
different techniques can be used to handle common challenges in time series modeling.

 ## Part 2 - Stationarity Analysis

   We will perform tests on the time series data to understand whether it is stationary or not. 
   The autoregressive modeling requires the time series data to be stationary. To test this, we will use the following test:

   Augmented Dickey–Fuller (ADF) test: If the p-value is <0.05, then our data is stationary otherwise our data is non-stationary.


## Part 3 - Time Series Transformations

We will transform the time series data so that it ends up having a more stationary mean and variance. 
To do this, we will use the following data transformations:

* Box-Cox transformation - Makes the variance constant in any time series data.
* Differencing - Make the mean constant in any time series data.
* Differencing + Box Cox Transformation - We apply Box-Cox and the differencing transformations on the training data so that the data is ready
                                          for autoregressive time series modeling.

Box-Cox transformation is used to make the variance of a time series stationary and differencing is used to make its mean stationary. 
Note that although these methods can be executed in any order, differencing is done after Box-Cox transformation in general.

## Part 4 - Autocorrelation Plots

We compute and visualize the autocorrelation function (ACF) and the partial autocorrelation function (PACF) plots for the time series data.
ACF and PACF as tools that help us understand whether past values of a time series affect its current value.

### 1. Autocorrelation Function (ACF)

How similar is today's value to values from previous time periods?

For example, suppose we have monthly sales:
    
    Jan   Feb   Mar   Apr   May   Jun
    100   120   130   125   140   150

ACF checks relationships such as:

    - Lag 1: Is this month's sales related to last month's sales?
    - Lag 2: Is this month's sales related to sales 2 months ago?
    - Lag 3: Is this month's sales related to sales 3 months ago?
    - And so on.

 Simple example

 If:

    ACF Lag 1 = 0.85

 It means there is a strong positive relationship between the current value and the value one period earlier.

 If:
 
    ACF Lag 1 = 0.05

There is almost no relationship.

    ACF considers both direct and indirect relationships.

### 2.  PACF — Partial Autocorrelation Function

PACF asks a slightly different question:

    “Does a previous value directly affect the current value, after removing the effect of the values in between?”

This is the important distinction.

# Why is Time Series Different?

Suppose we have house prices.

    House       Area          Price
      A         1200	       50L
      B	        1500	       60L

Each row is independent.

This is normal supervised learning.

Now consider sales.

      Month	     Sales
       Jan	       100
       Feb	       120
       Mar	       150

March depends on February.

February depends on January.

Previous values influence future values.

This dependency makes Time Series unique.

# Components of Time Series

Almost every time series contains four important components.

## 1. Trend

### Upward Trend 
   
    When a time series shows a consistent increase in values over time, it is called an uptrend.

### Downward trend 

    When a time series shows a consistent decrease in values over time, it is referred to as a downtrend.

Looks like seasonality but lasts much longer.

Example

      ↓

      Recovery
      ↓

Not fixed like seasonality.

Random fluctuations.

      103

      102

Small unpredictable changes.
